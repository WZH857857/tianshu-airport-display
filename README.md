# 天枢·空港智显

基于安路科技 EG4S20 系列 FPGA 的智慧机场航显与应急监测系统，面向智慧机场航显、空港信息发布与应急联动场景。

本仓库为参赛作品的完整项目工程，由三块自主设计的 FPGA 板卡工程与一套配套上位机软件组成：

| 组成 | 平台 | 说明 |
| --- | --- | --- |
| 主板（HDMI 多媒体航显） | HX4S20C / EG4S20BG256 | TF 卡图片播放、SDRAM 多帧缓存、HDMI 显示与内嵌音频、字幕与航班看板 OSD、火灾应急模式 |
| 应急检测装置 | EG4X20B / EG4X20BG256 | 火焰、温湿度、人体感应等传感器采集，本地小屏显示，异常上报 |
| 视觉摔倒检测副卡 | EG4S20NG88 | 摄像头采集与全硬件摔倒/人群检测，HDMI 标注输出 |
| 上位机 | Python（Windows） | USB 串口 / 蓝牙 SPP 实时控制：图片与字幕下发、航班看板编辑、时间同步、亮度对比度调节、火灾模式与应急状态监控 |

## 快速开始

### 上位机

- 直接运行 `05_上位机可执行程序/天枢空港智显上位机.exe`（免安装 Python 环境）；
- 或运行源码：`01_主板工程_HDMI多媒体航显/上位机源码/airport_console.py`（Python 3.10+，依赖 PyQt）。

### FPGA 工程

1. 用安路 TD 打开对应的 `.al` 工程，确认目标器件与约束文件；
2. 综合、布局布线生成位流，或直接使用 `04_最终位流文件` 中已编译好的位流；
3. 主板：烧录位流后插入 TF 卡，连接 HDMI 显示器与 USB 串口；
4. 应急装置：烧录位流，连接传感器、蓝牙模块与小屏；
5. 视觉副卡：烧录位流，连接摄像头与 HDMI 显示设备。

完整复现步骤与打包范围说明见 `00_代码与复现说明.md`。
