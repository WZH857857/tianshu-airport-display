# KEY1 后台预装换页（V5，2026-09-26）

## 问题

V4 已经避免了 KEY1 装载中止后的错乱，但按键后仍要等 TF 卡把下一张
640 x 480 BMP 从 SPI 卡读完整，受 2.8 MHz SPI 限制，现场感觉不是
“立即切图”。

## V5 方案

- `frame_store` 新增 `DEFER_SWAP`、`swap_req`、`preload_ready` 和
  `swap_done`。
- 第一张完整帧自动上线；后续完整帧先停留在离屏 SDRAM 缓冲区。
- 当前图片显示期间，`player_ctrl` 后台预装下一张。
- KEY1 或 3 秒自动轮播到期只发 `swap_req`，显示侧在下一视频帧边界
  发布新缓冲区。
- 预装未完成时按键请求会锁存，读完下一张后立即换页。
- 第一张图片上线前仍保留 V4 的硬跳过路径。

## 下载与预期

下载模式选 **`PROGRAM_SRAM`**，下载时钟建议 **5 MHz**，不要选
`PROGRAM_FLASH`。稳定显示图片时灯码为 `0010`。按 KEY1 后 LED1 亮约
0.5 s；如果下一张已经预装完成，画面应在一个视频帧左右，约 `16.7 ms`
后切换；如果按得太早，画面会在下一张读完时立即切换。
