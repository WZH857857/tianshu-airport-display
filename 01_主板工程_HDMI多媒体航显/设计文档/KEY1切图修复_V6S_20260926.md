# KEY1 保守快速预装换页（V6S，2026-09-26）

## 用途

V6 把 TF 卡高速读取提高到 12.5 MHz。如果这张卡或转接板在高频下出现
读卡错误、白屏或完全不能切图，用 V6S 回退到更稳的 8.33 MHz。

V6S 不改变 V5 的播放状态机，只修改高速 SPI 分频：

```text
SPI_LOW_SPEED_DIV  = 16'd248  -> 初始化约 100 kHz
SPI_HIGH_SPEED_DIV = 16'd2    -> 数据读取约 8.33 MHz
```

## 下载与判读

下载模式选 **`PROGRAM_SRAM`**，下载时钟建议 **5 MHz**。稳定显示图片时
状态码为 `0010`，即只有 `LED2` 常亮。短按 `KEY1` 后 `LED1` 亮约
0.5 s 作为确认。若 V6S 仍不能切图，需要记录按键后的四位灯码：

```text
LED4 LED3 LED2 LED1
```

其中 `LED3` 亮通常表示卡 / FAT32 / BMP 文件问题，`LED4` 亮表示显示侧
欠载。这个灯码可以区分读卡失败和换页延迟。
