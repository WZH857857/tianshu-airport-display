# KEY1 快速预装换页（V6，2026-09-26）

## 现象

V5 已经在图片保持阶段后台预装下一张，按键逻辑只等待 SDRAM 帧边界。
但 V5 的 SPI 高速分频为 `16'd8`，TF 卡读取时钟约为 2.8 MHz。一张
921 KB 的 640 x 480 24 位 BMP 需要约 2.6 s 才能读完，因此在刚进入
保持阶段或自动轮播到期时，预装尚未完成，KEY1 仍会表现为等待后换图。

## V6 修改

只修改 `rtl/hdmi_mm_player.v` 中的 `SPI_HIGH_SPEED_DIV`：

```text
V5: 16'd8   -> 约 2.8 MHz
V6: 16'd1   -> 12.5 MHz
```

TF 卡初始化阶段仍使用 `SPI_LOW_SPEED_DIV = 16'd248`，约 100 kHz。
只有在 SD 卡完成 CMD0 / CMD8 / ACMD41 / CMD58 等初始化握手后，才切到
12.5 MHz 进行 CMD17 单块读取。

## 效果

- 921 654 字节 BMP 的理论连续读取时间：约 0.59 s；
- 加上 FAT32 目录、簇链和扇区命令开销后，正常仍应远小于 1 s；
- 预装完成后，KEY1 仍只等待下一个视频帧边界，约 16.7 ms 换图；
- 如果按键发生在预装未完成时，请求会被锁存，读完下一张后立即换页。

## 下载与判读

下载时选 **`PROGRAM_SRAM`**，下载时钟建议 **5 MHz**，不要选
`PROGRAM_FLASH`。稳定显示图片时状态码为 `0010`，即只有 `LED2` 常亮。
短按 `KEY1` 后 `LED1` 亮约 0.5 s 作为确认，下一张图片应在预装完成后
一个视频帧左右出现。如果 12.5 MHz 下出现读卡错误或白屏，回退到 V5：

```text
hdmi_audio_release_PRELOAD_V5_20260926.bit
```
