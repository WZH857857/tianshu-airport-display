## 1. 问题

板级现象：声音已经能通过显示器扬声器放出，但**每次按键切图，音乐都会从头
重放**。原来的 do-re-mi 测试音是八音循环，切图时听到的就是"哆来咪"重新
起头，放在机场航显场景里既不像背景音乐，也把"切图"和"换歌"这两件事绑在
了一起。

要求有两条：

1. 切图**不能**重置音乐，音乐必须连续播放；
2. 音色/内容要符合机场航显场景，不要是一段循环测试音。

## 2. 根因

旧实现的音频模块带一个 `I_restart` 端口，顶层把 KEY1 的按键脉冲接了上去：

```verilog
// 旧代码：按键 -> 音频模块复位到第一个音符
always @(posedge sys_clk or negedge sys_rst_n)
    if (mode_pressed) restart_tog <= ~restart_tog;

hdmi_audio_tone_i2s_64fs u_audio_tone (
    .I_restart (audio_restart),   // <- 每次切图重放 do-re-mi
    ...
);
```

模块内部 `I_restart` 直接把音符指针、相位累加器和包络一起清零，所以按键切图
和音乐重放是同一根信号驱动的，靠时序绕不过去，只能改接口。

## 3. 新的音频设计

### 3.1 连续机场广播提示音，没有"重启"这个概念

`rtl/audio/hdmi_audio_tone_i2s_64fs.v` 重写后**彻底删掉 `I_restart` 端口**，
只保留一条三步循环：E5 (659 Hz) -> C5 (523 Hz) -> 静音。E5 到 C5 是下行
大三度，就是机场广播前"叮咚"提示音的音程；静音段让每遍提示音之间有呼吸，
循环播放时不会像测试音一样连续鸣叫。

| 项目 | 参数 |
| --- | --- |
| 节拍单位 | `UNIT_FRAMES = 2400`，即 48 kHz 下 **50 ms** |
| 提示音步长 | E5 10 个单位 (500 ms)，C5 14 个单位 (700 ms)，静音 24 个单位 (1.2 s) |
| 循环长度 | 3 步共 48 个单位 = **2.4 s** 一循环 |
| 波形 | 相位累加器最高位取出的**三角波**（不是原来的方波，高频谐波少很多） |
| 包络 | 每个音符 起音 -> 指数衰减 -> 放音尾，用移位衰减实现 0..7 级 |
| 输出电平 | 三角波峰值 `64 << 15 = 2 097 152`，与旧测试音同量级 |

包络和乐句表都在模块内用 `case` 实现，**不消耗乘法器**（衰减是移位，不是
乘法），所以新增音色没有推高 DSP 占用之外的综合难度。

### 3.2 切图提示音：混音，不打断

切图动作改成一个**提示音（cue）**：784.0 Hz（G5，属音）的短铃音，
200 ms、比背景提示音低 6 dB，**叠加在正在播放的提示音序列之上**，背景
E5/C5 序列本身继续走。

```verilog
hdmi_audio_tone_i2s_64fs #(
    .BGM_SHIFT   (15),              // 三角波峰值 2.097 M
    .CUE_SHIFT   (14),              // 切图提示音比背景提示音低 6 dB
    .UNIT_FRAMES (2400),            // 50 ms 一个节拍单位
    .CUE_FRAMES  (9600)             // 200 ms 提示音
) u_audio_tone (
    .I_cue (audio_cue),             // 只混音，不重置
    ...
);
```

混音在 25 位有符号数上做饱和相加，提示音叠加时不会溢出回绕。

### 3.3 提示音与画面严格同时

提示音由 `frame_swap_done` 触发，而不是 KEY1 的按键脉冲：

- `frame_swap_done` 是**显示侧真正接受了新缓冲区**那一拍的脉冲，KEY1 手动
  切图和 6 秒自动轮播走的是同一条路径；
- 因此提示音和画面变化在同一帧发生，**自动轮播也会响**，而旧做法只挂
  KEY1，自动切图是静音的；
- `frame_swap_done` 在 `sys_clk` 域，音频在 `audio_mclk` 域，中间仍是
  "翻转成 toggle + 三级同步器"的跨时钟结构，不会出现窄脉冲丢采样。

| 观测 | 含义 |
| --- | --- |
| E5 / C5 半周期落在 33..41 / 41..51 帧 | 循环表就是机场广播的"叮咚"两音，不是旧 do-re-mi |
| 提示音之后测得的半周期仍是 46 帧（C5 区间） | **切图后序列没有回到第一声 E5**，重启缺陷已消除 |
| 切图提示音期间峰值从 1 048 576 抬到 1 556 480 | 切图 G5 提示音确实混进了正在播放的 E5/C5 序列里，而不是替换它 |
