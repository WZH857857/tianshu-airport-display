## 1. 目标

题目原文：

> (5) 音频可视化表现：尝试结合音频数据生成频谱或波形显示，叠加于视频画面，
> 增强交互展示效果。

本版在已经完成的人声播报和 HDMI I2S 音频输出之外，增加两块实时可视化：

1. 128 点音频波形；
2. 8 段频谱能量柱。

两块内容放在画面右下角原有信息面板的位置，不遮挡主机图片的主要区域，
也不改变 HDMI 音频前级的采样率、I2S 时序、人声 FIFO 和切图逻辑。

## 2. 数据来源与集成位置

音频数据取自 `hdmi_mm_player` 中 HDMI 发送核的 `audio_left` 24 位采样，
采样有效脉冲是 `audio_valid`。这两个信号已经在像素时钟域，所以
`ui_overlay` 可以直接使用它们，不新增跨时钟域 FIFO：

```text
HDMI I2S / audio island
  -> audio_left[23:12] / audio_valid
  -> ui_overlay 内的波形历史 RAM
  -> ui_overlay 内的 7 级一极点滤波器组
  -> 8 段能量档位
  -> 右下角 256 x 128 像素叠加层
  -> 原有 OSD 优先级和最终 RGB 输出
```

波形历史深度为 128 个样本，按 48 kHz 计算约 2.7 ms。写入指针只在
`audio_valid` 时推进，因此切图、转场、自动轮播和按键都不会影响音频
采样序列。

## 3. 算法

### 3.1 实时波形

每个有效音频采样写入 128 深的 `sample_mem`，以采样写入指针作为最新样本的
基准。绘图时采样历史整体向左侧滚动，最新样本固定出现在右侧：

```text
wave_raw = sample_mem[(wave_col + wave_wr_ptr) & 0x7F]
```

取 12 位有符号幅值的高 8 位，再映射到 64 像素高度的波形区。原始数据没有
做重采样；波形区每列对应一个历史样本，水平方向 2 像素一列，折线每点画
2 像素高，中轴用暗青色标出。

### 3.2 8 段频谱

频谱没有使用 FFT，目的是避免引入乘法器阵列和额外的 BRAM。实现采用
7 个一极点低通滤波器：

```text
y[i] = y[i] + ((x - y[i]) >>> k)
```

系数依次为：

| 滤波器 | 移位 | 系数 |
| --- | --- | --- |
| LP0 | `>>> 7` | 1/128 |
| LP1 | `>>> 6` | 1/64 |
| LP2 | `>>> 5` | 1/32 |
| LP3 | `>>> 4` | 1/16 |
| LP4 | `>>> 3` | 1/8 |
| LP5 | `>>> 2` | 1/4 |
| LP6 | `>>> 1` | 1/2 |

相邻低通输出相减，得到 8 个频带的带通信号：

```text
band0 = LP0
band1 = LP1 - LP0
band2 = LP2 - LP1
...
band6 = LP6 - LP5
band7 = input - LP6
```

随后每一带做三件事：

1. 取绝对值完成整流；
2. 用 `env += (mag - env) >>> 4` 做包络平滑，保证语音音节有可见的起音；
3. 按 2 的幂次阈值映射成柱高档位，最高档为 56 像素。

柱高在视频帧边界更新，起音直接取本帧较大的值，回落每帧减 1 个像素。
这样既不会被单个音频采样抖动，又能在照片或录像中保留短促语音的可见高度。

### 3.3 画面布局

可视化区域从 `(384, 320)` 到 `(639, 447)`，共 256 x 128 像素：

| 区域 | 坐标 | 内容 |
| --- | --- | --- |
| 波形 | `y = 320..383` | 128 点实时波形、2 像素高折线、中轴 |
| 频谱 | `y = 384..447` | 8 根 28 像素宽柱、4 像素间隙、3 dB 网格 |

柱色按频段分为：

* 低频：绿色 `00FF80`；
* 中频：青色 `00E0FF`；
* 高频：橙色 `FFB020`；
* 网格：暗青色 `006080`；
* 波形：亮青色 `00FFFF`。

面板只在 `OSD FULL`（`ui_mode = 0`）显示；`INFO / ON / OFF` 布局不显示
波形和频谱。顶层参数 `FEATURE_AUDIO_WAVE` 已设为 1，该参数关闭时整块
可视化面板不会改变任何像素。

## 4. 验证

### 4.1 音频可视化仿真

新增 `sim/tb_audio_vis.v`。测试台以 48 kHz 的有效节拍分别输入 300 Hz 和
12 kHz 正弦波，直接观察滤波器档位，并扫描右下角 256 x 128 区域逐像素
核对波形、柱形、面板边界和关闭路径。

运行结果：

```text
VIS TB: 300 Hz bands = 24 24 24 24 20 20 16 20
VIS TB: 12 kHz bands = 16 16 0 8 16 20 24 32
VIS TB: panel hits = 32768, waveform pixels = 512, spectrum pixels = 3892
VIS TB: bar pixels = 476 476 0 252 476 588 700 924
AUDIO VIS TB: PASS
```

检查内容：

* 300 Hz 时低频段能量明显高于高频段；
* 12 kHz 时最高频段达到 32 档，与 300 Hz 时该带的 20 档明显分开；
* 8 根柱的像素数分别等于 `(档位 + 1) * 28`；
* 波形像素和频谱像素都实际到达 RGB 输出；
* `OSD INFO`、`OSD OFF` 和 `wave_enable = 0` 时面板像素为 0。

预览图：`sim/build_adv08/audio_vis_preview.png`。图中上半部分是波形，
下半部分是 8 根能量柱。

### 4.3 时序与资源

TD 完整流程使用 `scripts/manual_build_adv08_audiovis.tcl`，放置种子为 1，
流程为 `elaborate -> optimize_rtl -> optimize_gate -> place -> route ->
fix_hold -> update_timing -mode final -> bitgen`。最终 QoR：

| 项目 | 数值 |
| --- | --- |
| 建立 WNS | +157 ps |
| 建立 TNS | 0 |
| 建立违例端点 | 0 |
| 保持 WNS | +24 ps |
| 保持 TNS | 0 |
| 保持违例端点 | 0 |
| slice | 9 075（92.60%） |

包络和像素比较逻辑。

## 5. 上板步骤

1. 在 TD 中选 `hdmi_adv08_audiovis.bit`，用 `PROGRAM_SRAM` 下载，
   不要烧写 flash；
2. TF 卡根目录放六个 ASCII 文件名的 BMP，以及 `VOICE.WAV`；
3. 用 `KEY4` 长按约 1 秒切到 `OSD FULL`；
4. 等图片进入自动轮播并开始机场提示音或人声播报；
5. 确认右下角上半部分有青色波形，下半部分有 8 根柱；讲话时中低频柱应
   随音节变化，音乐中的高频内容应抬高右侧柱；
6. 按 `KEY1` 或等待 6 秒自动切图，确认音乐不重新开始、波形不中断；
7. 再按 `KEY4` 切到 `INFO / ON / OFF`，确认可视化面板按预期隐藏。

## 6. 当前限制

* 频谱是 8 段能量指示，不是带数值刻度的 FFT 分析仪；它强调实时性和
  资源占用，适合比赛现场展示。
* 可视化目前只在 `OSD FULL` 显示，这是为了不覆盖 INFO 布局中的更多
  信息文字。
* 本版已完成 RTL 仿真、综合、布局、布线、保持修复和 bitgen，尚未做板级
  实测。板级实测时应重点观察波形活动、8 段柱变化和切图时音频连续性。
